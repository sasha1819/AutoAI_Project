# Diagnosis fixtures

Three real, confirmed test failures on the sample shop, used to record Claude's diagnoses and to replay them offline:

| Case | Spec | What is really wrong |
| --- | --- | --- |
| `app-bug-cart-1-2` | `specs/cart-1-2-discount-codes-are-case-insensitive-save10.spec.ts` (generated by Claude in M1) | The app: lower-case discount codes are rejected (the planted Cart 1.2 mismatch). |
| `test-bug-cart-1-1` | `specs/cart-1-1-add-to-basket.spec.ts` | The test: it clicks "Add … to basket", but the button says "to cart". |
| `environment-account-3-1` | `specs/account-3-1-order-history.spec.ts` with `configs/login-setup.playwright.config.mjs` | The environment: the test needs a login setup project and a saved session that AutoAI does not run. |

`runs/<case>.json` is the saved run (`repoRoot` replaced by `<repo>`). The recorded prompts and answers are in `fixtures/recorded/claude-diagnosis/`. Re-record with `node scripts/record-diagnoses.mjs` (needs `ANTHROPIC_API_KEY`, about $0.10).
