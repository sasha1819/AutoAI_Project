Idea: $ARGUMENTS

1. Read `docs/PRD.md` Sections 1 and 10 and `docs/LATER.md`.
2. Answer in this format:
```
VERDICT: MVP | LATER | ALREADY IN PRD
Why: <two sentences, tied to the core loop: scan -> findings -> generate -> run -> diagnose>
Effort (solo): small | medium | large
```
3. If LATER, append a line to `docs/LATER.md` (`- [ ] <idea> — <one-line reason>`). Do not write any code.
4. Only say MVP if the product cannot be shown to a first real user without it.
